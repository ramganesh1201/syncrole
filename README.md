## 🛠️ Tech Stack

* **Frontend Framework:** React + Vite
* **Language:** TypeScript
* **Styling & UI:** Tailwind CSS, shadcn/ui
* **Backend & Database:** Supabase (PostgreSQL, Authentication, Realtime)
* **Package Manager / Runtime:** Bun
